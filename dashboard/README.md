Dashboard for [open-predico](https://github.com/arnaud-vs/open-predico). Reads backtest predictions from the public dataset [open-predico/benchmark](https://huggingface.co/datasets/open-predico/benchmark).

Streamlit app run in the browser with [stlite](https://github.com/whitphx/stlite) (static Space, no server). Locally: `pip install -r requirements.txt && streamlit run app.py`.
