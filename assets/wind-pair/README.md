# Historical 50Hertz wind-pair bootstrap

This directory contains one reviewed, immutable bootstrap fixture, published explicitly for
reproducible initialization of the optional T0-gamma + Timestral wind pipeline. It is a scoped
exception to the repository's general rule that data belongs on Hugging Face.

## Available fixture

- Release: **12 November 2026**, reviewed historical release.
- Archive: `wind-pair-clean-seed.zip` (18,669,019 bytes).
- SHA256: `c365764f50b90d4738c4bf64b2398aa5dad7717461796823ec3af23ddcc03ade`.
- `wind-pair-clean-seed.zip.sha256`: verification file.
- `audit.json`: readable inventory, time ranges and publication checks.

From the repository root:

```sh
(cd assets/wind-pair && shasum -a 256 -c wind-pair-clean-seed.zip.sha256)
uv run --with modal==1.6.3 modal run src/openpredico/live/modal_wind_pair.py::bootstrap --seed assets/wind-pair/wind-pair-clean-seed.zip
```

Follow [the operator guide](../../docs/wind-pair-operations.md) for secrets, cloud smoke,
deployment, timing and rollback. Publishing this archive does not deploy either Modal app.

## Contents and historical status

| Content | Coverage/purpose |
|---|---|
| Decoded component weather | 22 April–5 November 2026, local delivery dates; 6 points per component, 4 weather models |
| Actual generation | Public ENTSO-E benchmark observations through 31 October 2026 UTC |
| `members.parquet` | 104 days of newly generated T0/Timestral historical hindcasts, 24 July–5 November; 29 July excluded for the original weather gap |
| `totals.parquet` | Historical pair point forecasts for those same days, used to initialize ensemble/conformal history |
| `banks/` | Speed-band routing parameters, not pretrained neural-model weights |
| Manifests | Configuration/model fingerprints, file checksums and clean-refit provenance |

No Parquet data extend beyond 5 November 2026. The bank filenames extend to delivery
13 November because they label parameter applicability; their latest training forecasts end
5 November. Historical hindcasts were generated retrospectively, and exact publication/revision
vintages are unverified. They are not records of official Predico contest submissions.
The fixture contains no live candidate bundles, credentials, tokens or model checkpoints.

The speed banks were fitted using independent T0-gamma raw-weather utility forecasts. T0 and
Timestral component/pair forecasts and calibration residual history were regenerated; no
TimesFM-derived weather banks or legacy forecast values enter this fixture. This seed is
sufficient to reconstruct bootstrap state, not the complete raw-run research dataset needed
to reproduce every historical inference from scratch. The seed builder is
[`tools/build_wind_pair_seed.py`](../../tools/build_wind_pair_seed.py).
